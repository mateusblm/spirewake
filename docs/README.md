# Documentação canônica do Spirewake

Este diretório contém a fonte de verdade do projeto. A documentação foi reorganizada para evitar um único arquivo gigante e para que Claude/Codex consigam localizar rapidamente a regra responsável por cada sistema.

## Estrutura

### `00-governance/`
Governança da documentação, precedência, status e decisões substituídas.

### `01-product/`
Visão do produto e escopo do Vertical Slice.

### `02-systems/`
Regras funcionais de Ascendentes, progressão, combate, Torre, economia, Base e expedição.

### `03-balance/`
Números canônicos e baselines de balanceamento.

### `04-ux/`
Fluxos funcionais aprovados. Layout visual final ainda será definido.

### `05-visual/`
Direção visual já aprovada e espaço reservado para Visual Bible/Golden Rig.

### `06-technical/`
Restrições técnicas já conhecidas. Arquitetura final ainda não foi desenhada.

### `07-agents/`
Fluxo de trabalho e regras específicas para agentes.

### `08-sprints/`
Área reservada para as sprints depois de UX, Visual Bible e arquitetura estarem congeladas.

### `09-backlog/`
Ideias futuras e itens explicitamente fora do Vertical Slice.
